# HackAndRoll 2026: Youtube Shorts Runner (Ultimate Edition)

This is the consolidated repository for the **HackAndRoll 2026** submission.
It combines a 3D Infinite Runner, a Productivity Blocker, and Annoying Browser Features into a single Chrome Extension.

## 📂 Project Structure
- **`src/`**: Source code (Game + Features).
- **`public/`**: Public assets and manifest.
- **`dist/`**: The **Build Output** (Load this in Chrome).
- **`package.json`**: Dependencies.

## 🚀 How to Build & Install

1.  **Build**: Double-click **`prepare_extension.bat`** in this folder.
    *   It will install dependencies and build the project.
    *   It will open the `dist` folder.

2.  **Install in Chrome**:
    *   Go to `chrome://extensions/`.
    *   Enable **Developer mode**.
    *   Click **Load unpacked**.
    *   Select the **`dist`** folder in this directory.

## 🎮 Features
1.  **Infinite Runner**: Play a Subways Surfers-style game next to YouTube Shorts.
2.  **Brainrot Blocker**: Productivity sites are blocked until you pass a brainrot quiz.
3.  **Hard to Close**: Tabs have "lives" (2-5) and refuse to close immediately.
